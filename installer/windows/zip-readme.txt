NIPAT Desktop - Windows ZIP completo

1. Estrarre completamente questo ZIP su un disco locale.
2. Fare doppio clic su 1_INSTALLA.cmd, senza eseguirlo come amministratore.
3. Attendere i controlli e aprire NIPAT Desktop ZIP dal menu Start.

Python 3.12.10, filesystem WSL e motore scientifico sono inclusi.
Non occorre installare Python. Windows potrebbe dover scaricare/aggiornare
WSL da Microsoft e richiedere autorizzazione amministrativa o riavvio.
Dopo un riavvio aprire NIPAT Desktop ZIP - completa preparazione.

L'applicazione viene installata in %LOCALAPPDATA%\NIPAT-Desktop-Zip.
Non cancellare questa cartella. Dopo la preparazione riuscita, la cartella
estratta e lo ZIP scaricato possono essere eliminati.
Dati e risultati risiedono nelle sottocartelle data e runs.
L'installazione EXE resta separata; i suoi dati non vengono trasferiti.
Gli aggiornamenti dal menu usano il canale ZIP completo.

Scaricare esclusivamente lo ZIP della release ufficiale e confrontare il
suo SHA-256 con SHA256SUMS. Lo ZIP Source code di GitHub non e un installer.
Questa distribuzione non disabilita i controlli di sicurezza Windows.
Smart App Control puo ancora bloccare script o componenti nativi: conservare
il messaggio e i log. La firma dell'interprete non firma il codice NIPAT.
