# Documentation archive

For installation and analysis, use the [current guides](../README.md). For an older installation, choose its version in the [historical documentation index](https://github.com/GregorioDalia/NewPat-Desktop/blob/c2b936b6d581137746b372b9bbade2318bae716c/docs/archive/README.md). Each link there opens the recorded release notes, development guide, or test procedure with its original supporting files.

The checkout keeps the audits used by acceptance records for [0.8.60](../AUDIT_0.8.60.md), [0.8.70](../AUDIT_0.8.70.md) and [0.8.80](../AUDIT_0.8.80.md). The [validation data](../validation) contain measured timings, scientific comparisons and test conditions for individual versions. Installed-package qualification is recorded separately in the [acceptance records](../../.github/release-acceptance).
